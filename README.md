# InvAnim

An interactive map of Space Invader street art mosaics, with animated
fly-throughs of the invasion.

Forked from the Space Invader map viewer by [pnote.eu](https://pnote.eu/projects/invaders/map/).
See [ATTRIBUTION.md](ATTRIBUTION.md).

Run it locally with any static server:

```bash
cd site && python -m http.server 8000
```
